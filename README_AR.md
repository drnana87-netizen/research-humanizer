# Research Humanizer — نسخة الويب الخاصة

هذه نسخة قابلة للنشر على الإنترنت وليست رابطًا منشورًا بالفعل. بعد النشر تحصلين على رابط HTTPS يمكنك فتحه من أي هاتف أو كمبيوتر بدون تثبيت أي برامج على أجهزة الاستخدام.

## النشر لأول مرة (باستخدام المتصفح فقط)

1. افتحي GitHub وأنشئي مستودعًا جديدًا خاصًا (Private repository). استخرجي محتويات ملف ZIP وارفعي **الملفات نفسها** إلى جذر المستودع (وليس ملف ZIP كاملاً). احتفظي بملف `render.yaml` في المجلد الرئيسي.
2. افتحي https://dashboard.render.com/ وسجلي الدخول. اختاري **New → Blueprint** ثم وصلي مستودع GitHub الخاص بالمشروع. وافقي على إنشاء خدمة الويب المحددة في `render.yaml`.
3. عندما يطلب Render متغيرات البيئة السرية، أدخلي القيم التالية **داخل لوحة Render، وليس داخل كود HTML أو GitHub**:

   `OPENAI_API_KEY` — مفتاح API من https://platform.openai.com/api-keys

   `APP_ACCESS_PASSWORD` — كلمة مرور خاصة قوية من 16 حرفًا على الأقل، ومختلفة تمامًا عن مفتاح API وعن كلمة مرور حسابك المعتادة.

4. انتظري اكتمال عملية Build/Deploy وظهور الحالة Live. انسخي رابط موقعك الذي ينتهي عادةً بـ `onrender.com` وافتحيه من الموبايل والكمبيوتر.
5. اكتبي **كلمة مرور الموقع فقط** في شاشة Unlock. لا تدخلي API key في الموقع إطلاقًا.

> قد يختلف اسم زر إنشاء Blueprint أو تصميم لوحة Render مع التحديثات. الاستضافة تعتمد على الحساب والخطة وحدود استخدامها. API منفصل في المحاسبة عن ChatGPT Plus.

## ما الذي يمكن فعله؟

- رفع PDF أو DOCX أو TXT أو MD (حتى 12 MB) أو لصق النص.
- إعادة الصياغة الطبيعية، تحسين Literature Review، تبسيط الكتابة الأكاديمية، إبراز النقد المدعوم بالمصادر، تحسين القواعد، وشرح المحتوى بالعربية.
- اختيار Undergraduate أو Master's أو DBA / Doctoral.
- عرض الأصل والنص المُعدَّل جنبًا إلى جنب، وحفظ Word أو TXT.
- فصل قائمة References إذا كانت مسبوقة بعنوان مستقل؛ وتقديم تحذيرات عند اختلاف أرقام أو اقتباسات مرجعية يمكن التعرف عليها نصيًا.

## خصوصية ومحدوديات مهمة

- مفتاح الـ API موجود في متغير سري على **سيرفر الاستضافة فقط** ولا يُرسل إلى المتصفح. يتم تسجيل الدخول بكلمة مرور مستقلة، مع جلسة تنتهي بعد 8 ساعات، وملف Cookie لا تقدر عليه JavaScript (`HttpOnly`, `Secure` على HTTPS، و`SameSite=Strict`).
- الملفات تُرفع إلى سيرفر الاستضافة لاستخراج نصوصها في الذاكرة، دون حفظ متعمد على القرص. النصوص المطلوب تعديلها تُرسل إلى OpenAI API عند الضغط على Rewrite. يطلب التطبيق `store=false`.
- الاستضافة والجهة المقدمة للـ API لهما شروط خصوصية واحتفاظ مستقلة. لا ترفعي أبحاثًا سرية أو غير منشورة بدون تصريح.
- المراجع ليست مُتحقَّقًا منها، والأرقام تُفحص بمقارنة نصية بسيطة فقط. يجب مراجعة المصادر والإحصاء يدويًا. ملفات PDF الممسوحة ضوئيًا تحتاج OCR خارج هذا التطبيق.
- التصدير إلى Word يولد مستند نصي منظم، ولا يضمن الحفاظ على التنسيق الأصلي أو الجداول أو المعادلات أو الصور.
- **لا يمكن ضمان المرور من برامج AI detection أو plagiarism detection.** التطبيق لتحسين القراءة والدقة وليس للتحايل على السياسات الأكاديمية. اتبعي سياسة جامعتك بشأن الاستخدام والإفصاح عن أدوات الذكاء الاصطناعي.
- لا تشاركي كلمة مرور الموقع مع أشخاص غير مخولين. أنشئي حدود إنفاق وتنبيهات في حساب API، ويمكنك تفعيل Cloudflare Access أو WAF لحماية أقوى عند مشاركة الرابط.

## لو مش حابة ترفعي ملفاتك إلى سيرفر الاستضافة

استخدمي النسخة المحلية السابقة أو انسخي فقرة محددة فقط بعد إزالة البيانات السرية؛ النسخة الويب ليست معالجة محلية بالكامل.

## الدعم الفني المختصر

- `API key missing on server`: تأكدي من حفظ متغير `OPENAI_API_KEY` في Render ثم إعادة النشر/التشغيل.
- `Incorrect access password`: استخدمي قيمة `APP_ACCESS_PASSWORD` المحددة في Render، لا مفتاح API.
- عدم القدرة على فتح الموقع: راجعي حالة الخدمة Live وسجلات الأخطاء في لوحة Render.
- ملف PDF فارغ: الملف قد يكون صورًا ممسوحة ضوئيًا ولا يحتوي على نص قابل للتحديد.

## بنية المشروع

- `index.html`: واجهة Responsive، لا تحتوي على مفتاح API.
- `server.py`: خادم HTTP للمصادقة، قراءة المستندات وتصدير Word واستدعاء OpenAI.
- `requirements.txt`: مكتبات بايثون التي تثبّتها الاستضافة آليًا.
- `render.yaml`: تعليمات نشر تطبيق الويب على Render.
- `tests/`: اختبارات داخلية للتحقق من أهم وظائف الحماية والملفات.

ملاحظة: إنشاء الرابط العام يتطلب نشر المشروع مرة واحدة من خلال حساب استضافة تملكينه. لا يمكن إنشاء رابط شخصي فعّال من مجرد تحميل ZIP.
